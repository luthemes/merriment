== Description ==
Merriment is a festive ClassicPress theme made to celebrate Christmas. It pairs a snowy header image and a cozy holiday background with evergreen, holly red and candlelight gold accents, and it is responsive and mobile ready.

== Installation ==
1. In your admin panel when logged in, go to Appearance -> Themes and Click on Add New.
2. Click on Upload and choose File, then select the theme's zip file and click Install Now.
3. Once the theme is installed, click on Activate to begin using this theme.

== Customizer ==
Go to Appearance -> Customize.
* Theme: Global - Background Image and Additional CSS.
* Theme: Header - Site Identity and Header Image. When the header image is removed, the site title and tagline show above the menu instead.
* Theme: Content - Homepage Settings and Layout (left sidebar, right sidebar or no sidebar).

Menus: assign a menu to Primary Navigation for the header and to Social Navigation for the icons in the footer. Social links to sites such as GitHub, Facebook or Instagram show as icons.

Widgets: the Primary Sidebar shows next to the content, and the Footer Sidebar above the footer credit.

On small screens, the menu opens from a Menu button at the bottom left corner of the screen, where it's easy to reach with your thumb.
